# Commercial capability summary

- **Recruiter:** Designed and implemented a disabled Twinfra reference for
  Keycloak/APISIX-secured DeepSeek planning, private Knative/vLLM inference,
  Kueue/MultiKueue GPU admission and SigV4 Spinifex capacity requests, with
  OpenBao CSI identities, durable resource limits and executable security tests.

For executives, the architecture connects interactive AI proposals with governed
batch capacity across local Kubernetes and an open-source infrastructure cloud.
Finite quotas, fixed job templates, scoped credentials and verified cleanup make
resource consumption reviewable. The H100 reference ceiling is four eight-GPU
nodes; the A100 fallback remains unmapped. This work supports a future hybrid AI
and simulation service, but does not demonstrate deployed availability, customer
isolation, performance, cost savings or production readiness. Commercial launch
requires site/hardware acceptance, storage and fabric tests, IAM/API operation
coverage, failure recovery and review of Spinifex's AGPL-3.0 license obligations.
