The approved WSL host-routing test fetched GitHub HEAD successfully; three
subsequent bounded repo-server fetches passed. `bpf.hostLegacyRouting=true` is
limited to the WSL profile, retaining native CNI, BPF masquerading, proxy
replacement and deny-all enforcement. This validates a workaround, without
claiming a complete upstream diagnosis or an availability SLO.

public keys. Initialization is PGP-only, 3 shares/threshold 2, storing ciphertext
in `platform-services/openbao-init-encrypted`; unseal is manual. Acceptance uses
check-only mode and cannot initialize even when valid keys later appear.
No passwords, token values, private keys or unseal shares are included here.
