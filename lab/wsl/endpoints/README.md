# CPU endpoint and observability lab

This profile extends the owned `vcloud-wsl-local` WSL cluster only. It runs
OpenBao 2.7.1, Keycloak 26.8.0, APISIX 3.19.0, Knative/Kourier 1.23.0,
Prometheus Operator 0.94.1, Prometheus 3.15.0, Grafana 13.2.3 and OpenTelemetry
Collector 0.162.0. Release manifests and image digests are frozen in
[artifacts.lock.json](artifacts.lock.json). No production SSoT identity changes.

The [milestone runbook](../../../docs/wsl-local-milestones-3-5.md) describes
provisioning order, actual endpoints, security gates, validation and recovery.

The GUI at <https://localhost:18443/admin/> needs a master-realm administrator;
discovery health alone does not provision one. Use the separate
[admin bootstrap and private password retrieval](../../../docs/keycloak-admin-access.md).

```bash
cd /mnt/e/vCloud
# Connected staging imports exact digests, not a public runtime fallback.
sudo python3 tools/stage_wsl_endpoints.py
sudo bash lab/wsl/endpoints/deploy.sh
sudo bash lab/wsl/endpoints/access.sh start
# After the referenced Git revision passes CI and is published on main:
sudo kubectl --kubeconfig=/etc/vcloud-wsl/kubeconfig.yaml --context=vcloud-wsl-local \
  apply -f lab/wsl/endpoints/argocd.yaml
sudo bash lab/wsl/test-e2e.sh
# Operator public keys remain operator-managed. Missing keys -> exit 3.
sudo bash lab/wsl/openbao-init.sh
```

All application containers run without root or capabilities, with RuntimeDefault
seccomp and read-only root filesystems. The added upstream APISIX controller/ADC
also meet restricted PSS but use writable container filesystems. Private configuration is rendered only
in memory-backed volumes. Identity databases reuse the vetted 4 GiB CNPG PV;
monitoring data is intentionally transient and bounded. There are no new host
mounts, CSI node components, GPUs, vLLM containers or Spinifex controllers.

`argocd.yaml` gives the existing Argo controller namespaced workload permissions
only. Publish its referenced Git revision before applying it. Knative/Prometheus
controllers and CRDs, dynamic node probe policies and Prometheus discovery Roles
remain bootstrap-owned; the new Roles grant no Secret writes or cluster-wide
write access. The existing controller's broad read-only discovery Role is
unchanged and includes Secret reads; production least-privilege review remains open.
`gitops/workloads.yaml` is generated by `tools/wsl_endpoints_gitops.py`.

The pinned upstream internal Knative Certificate API is served and not
deprecated despite its alpha suffix. Strict validation uses its actual local
CRD schema. Prometheus service discovery uses EndpointSlice.

The [LocalStack extension](../localstack/README.md) changes only the WSL gateway
to authenticated TLS API-driven standalone mode so real `ApisixRoute` resources
reconcile. It preserves the CPU demo and smoke routes, supplies the pinned
2.2.0 controller/0.27.1 ADC prerequisites, and keeps admin port 9180 private.
