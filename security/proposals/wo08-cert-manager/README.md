## Reproduce after the governance PR merges

The batch is generated by the reviewed `toolchain_wave.review` function, rather than edited by hand. From the repository root after #67 is merged:

```python
import json, sys
from datetime import date
from pathlib import Path
sys.path.insert(0, 'tools/ci')
import toolchain_wave
root = Path('security/proposals/wo08-cert-manager')
evidence = json.loads((root / 'assessment.json').read_text(encoding='utf-8'))
result = toolchain_wave.review(
    evidence['findings'], eligible_fixed_release=evidence['eligibleFixedRelease'],
    controls={'clusterOrLanOnly': True, 'noExternalService': True,
              'externalEgress': 'Kubernetes API server'},
    upstream_evidence=evidence['upstreamReleaseEvidence'],
    on=date.fromisoformat(evidence['date']))
assert not result['nonQualifying'] and not result['blockers']
batch = {'version': 1, 'exceptions': result['proposedExceptions']}
assert batch == json.loads((root / 'exception-batch.json').read_text(encoding='utf-8'))
```

Update the evidence and regenerate after any scanner/package/fix/KEV/upstream change. Copy no proposal into `security/vulnerability-exceptions.json` until the owner approves it and the actual admission scan passes. No Dell connection, key ceremony, certificate replacement or GitHub settings change occurred.
